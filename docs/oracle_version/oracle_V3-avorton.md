## 📊 MATRICE DE DÉCISION (V3)

### Cas : "Culpabilité" détectée

```
Q3.includes("coupable") ou Q3.includes("honte")
├─ Si "un poil coupable" + autres N1/N2 green
│  └─ IGNORER (-0) → C'est du bruit
├─ Si "culpable" seule (sans modération)
│  └─ RED N2 (-3) → Hameçon probable
└─ Si "très coupable" / "honteuse" + aucun green N1
   └─ RED N2 (-3) → Obligation déguisée
```

### Cas : "Flemme" détectée

```
Q1.includes("flemme")
├─ Si N1 green présent (fierté, regret massif)
│  └─ ORANGE N2 (-1) → Inertie ignorable
├─ Si Q3 montre "change rien" / "osef"
│  └─ RED N2 (-3) → Vraie résistance
└─ Sinon
   └─ ORANGE N3 (-2) → Flemme neutre
```

### Cas : "Soulagement si pas fait"

```
Q3.includes("soulagé") ou Q3.includes("tranquille")
├─ Si aussi N1 green présent
│  └─ Conflit : garder RED N2 (-4) [soulagement > fierté]
└─ Sinon
   └─ RED N2 (-4) → Hameçon pur
```

## 📝 NOTES DE CODAGE (V3)

1. **Sensibilité casse** : toujours `.toLowerCase()` avant test
2. **Chevauchement** : un mot peut matcher plusieurs patterns → ordre d'évaluation compte
3. **Contexte Q3/Q4** : inverser polarité mentalement (regret = apparition green, soulagement = apparition red)
4. **Exclusions** : "un poil" / "un peu" neutralisent certains patterns
5. **Score contextuel** : certains keywords montent/baissent selon Q2 (valeur) détectée
